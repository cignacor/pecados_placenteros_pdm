# Pecados Placenteros — Product Overview

Pecados Placenteros is a mobile restaurant app (iOS/Android/Web) for a themed burger & food restaurant. The brand identity is dark, premium, and "sinful" — deep reds (`#cc0000`) on near-black backgrounds (`#1a0000`), with Playfair Display typography throughout.

## Core Features

- **Home** — Hero banner, featured menu items, loyalty club ("Club del Pecado") teaser
- **Menu (Carta)** — Full menu browsable by category (BURGERS, ENTRANTES, POSTRES, BEBIDAS), with search and scroll-to-category
- **Cart** — Add/remove items, quantity control, checkout flow via `CheckoutModal`
- **Reservar** — Table reservation screen
- **Perfil** — User profile and account management
- **Admin Panel** — CRUD for menu products (name, price, description, image URL, category, featured flag); accessible only to admin-role users

## User Roles

- `customer` — default role assigned on registration
- `admin` — can access the admin panel to manage products

## Language

The app UI is in **Spanish**. All user-facing text, labels, alerts, and copy should be written in Spanish.
